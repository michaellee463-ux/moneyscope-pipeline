## What failed

### 1. `bash pipeline/setup.sh` exits 1 (repo bug)
```
pipeline/setup.sh: line 14: SUDO: unbound variable
```
Cause: line 13 sets `SUDO` inside a subshell `( ... )`, so the variable never exists in the
parent shell, and `set -u` aborts on line 14. Because of this, Blender was never installed
and the Kokoro model files (`models/kokoro-v1.0.onnx`, `models/voices-v1.0.bin`) were never
downloaded, so `run.sh` cannot build a video.

Fix (replace line 13):
```bash
SUDO=""; sudo -n true 2>/dev/null && SUDO=sudo
```
(The cloud container runs as root and has `/usr/bin/sudo`; `blender` is not on PATH.)

### 2. Primary sources are blocked by the session network policy
`www.irs.gov` is refused by the egress proxy (`curl: (56) CONNECT tunnel failed, response 403`)
and WebFetch reports `getaddrinfo ENOTFOUND www.irs.gov` (host outside the allowed network
domains). The standards require every number to come from a primary source opened in the run,
so the run cannot verify figures from IRS (and most likely SSA, BLS, Census, Fed, Treasury, CFPB).
